## 📖 故事梗概

殷商时期，陈塘关矗立于东海之滨。守关将领李靖等待着第三个孩子的降生——这场怀胎已持续了三年六个月。最终产出的并非婴儿，而是一个通体泛着金色微光的肉球。李靖挥剑劈之，一个男孩从中跳出：**哪吒**——注定要震动龙宫的孩子。

七岁的哪吒手持乾坤圈与混天绫，在海中沐浴——却无意间撼动了水晶宫。龙王的夜叉将领前来问罪；哪吒奋起反击。三太子敖丙出战，亦被击败。当四海龙王齐聚陈塘关城门前，强令李靖交出其子时，哪吒做出了一个将回响两千余年的抉择：

> *"析骨还父，析肉还母。"*

他倒下了。但死亡并非终结。师父太乙真人以莲藕与荷叶为其重塑肉身。哪吒浴火重生——更加强大，手持火尖枪，脚踏风火轮。他击败了四海龙王，终结了他们对人间的暴政。

**寓意：** 正义有时需要非凡的勇气——面对自己行为后果的勇气，为他人牺牲的勇气，以及带着信念重新崛起的勇气。真正的力量不是权力，而是道德责任。

## 🛠️ 技术栈

- **前端** — 原生 HTML、CSS、JavaScript（零依赖）
- **插图** — Cloudflare Workers AI（FLUX-1-schnell），工笔重彩提示词
- **朗读** — Edge TTS（`edge-tts` Python 库）

### 生成素材

```bash
# 1. 生成插图（需要 Cloudflare API 密钥）
python3 generate-images.py

# 2. 生成音频朗读
python3 generate-audio.py

# 3. 本地运行
python3 -m http.server 8000
# → http://localhost:8000
```

## 🎨 设计理念

视觉设计灵感来源于**工笔重彩**绘画——唐、明两代宫廷插画的精细、饱和技法。与姊妹故事书应用的水墨（水墨）风格不同，哪吒采用**暗色丝绸底色**，使宝石般的矿物颜料如博物馆灯光下的画作般熠熠生辉。

**五色（五色）：** 朱砂红 · 石青蓝 · 金色 · 石绿 · 墨黑

界面体现了故事的核心二元性：**火与莲**——毁灭性力量与修复性纯洁的对立。朱砂火星如风火轮的火花般上升；粉色莲花瓣如重生般下降。进度条是石青蓝的潮汐。音频控制台是龙鳞鼓。章节分隔符是一枚朱砂莲花瓣印章。
